# Лабораторная работа № 6 — система «Больница»

Учебное веб-приложение на C# моделирует госпитализацию, ведение электронной медицинской карты, лечение по назначениям врача и выписку пациента. Интерфейс на русском языке реализован на ASP.NET Core MVC.

## Запуск

Требуется .NET SDK 10. Из каталога проекта выполните:

```bash
dotnet run --project Hospital.Web
```

При первом запуске создается `Hospital.Web/App_Data/hospital.json` с каталогами отделений, врачей и медсестер. Карты пациентов сохраняются в этом же файле между запусками.

## Слои приложения

```text
Hospital.Web (Presentation Layer, ASP.NET Core MVC)
          ↓
Hospital.Services (Service Layer, фасад сценариев)
          ↓
Hospital.Data (Data Access Layer, JSON-репозиторий)
          ↓
Hospital.Business (сущности, перечисления и правила валидации)
```

- **Hospital.Business** — пациент, назначение, запись ЭМК и выписной эпикриз; проверки обязательных данных и правил назначения.
- **Hospital.Data** — интерфейс репозитория и реализация чтения/записи локального JSON-файла.
- **Hospital.Services** — сценарии госпитализации, добавления и выполнения назначений, а также выписки.
- **Hospital.Web** — MVC-контроллеры и представления; контроллеры используют фасад сервисного слоя.

## Реализованные сценарии

1. Дежурный врач регистрирует пациента, диагноз при поступлении, отделение и лечащего врача. При госпитализации создается ЭМК и первая запись осмотра.
2. Лечащий врач добавляет медикаментозные, диагностические и профилактические назначения. Для инъекции задается количество, для таблеток — дозировка и число дней.
3. Медикаментозное назначение закрепляется за медсестрой; остальные виды — за врачом. После выполнения назначение и исполнитель фиксируются в ЭМК.
4. Выписка доступна после выполнения всех назначений. Система формирует эпикриз с данными пациента, датами пребывания, диагнозом и перечнем выполненного лечения.
